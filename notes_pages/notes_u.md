## Unzip files

### Unzip .bz2 tarball

``` bash
tar -xjvf file.tar.bz2
```

## URL shorteners

### Get the real URL and stats

- bit.do:  Change `http://bit.do/eiwE`  to: `http://bit.do/eiwE-`
- bit.ly:  Change `https://bitly.com/1en9OdU`  to: `https://bitly.com/1en9OdU+`
- is.gd:   Change `http://is.gd/FBrAQX`  to: ` http://is.gd/stats.php?url=FBrAQX`
- goo.gl:  Change `http://goo.gl/bvJGuS`  to: `http://goo.gl/bvJGuS+`
- goo.gl:  Change `http://goo.gl/bvJGuS`  to: `http://goo.gl/bvJGuS.info`
- tiny.cc:  Change `http://tiny.cc/ozfd9w`  to: `http://tiny.cc/ozfd9w~`
- tinyurl.com:  Change `http://tinyurl.com/mjnt93r`  to: `http://preview.tinyurl.com/mjnt93r`
- v.gd:    Change `http://v.gd/yKvI5m`  to: `http://v.gd/stats.php?url=yKvI5m`
